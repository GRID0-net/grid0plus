# internal/nintendo

The list of Nintendo hostnames SwitchNet replaces, and which service answers
each. **This is the single source of truth**, and it exists because three
artefacts have to agree exactly:

| Artefact | Generated by | Consequence of disagreement |
| --- | --- | --- |
| `switch/hosts.txt` | `switchnetctl hosts` | the console sends a request to real Nintendo, or nowhere |
| the nginx routing map | `switchnetctl nginx` | the console reaches the wrong service and gets an answer it cannot parse |
| the certificate SANs | `scripts/gen-certs.sh`, via `switchnetctl sans` | the handshake fails with nothing in any log naming the missing hostname |

Adding a host in one place and forgetting it in another produces a failure with
no useful error. Adding it here fixes all three.

Reference: [Server List](https://github.com/kinnay/NintendoClients/wiki/Server-List).
The host list also draws on
[Nextendo's Prelude-Nro](https://github.com/NextendoNetwork/Prelude-Nro), which is
running in production and has already found the entries a wildcard misses.

## Ordering matters

Atmosphère's DNS-MITM applies the **last matching line**. `Hosts` is declared in
the order it should be written, so broad entries come first and specific
overrides last — which is why the `nncs2` line comes after `nncs1`.

In the hosts file, `*` matches zero or more characters and `%` expands to the
environment (`lp1`). Those are DNS-MITM patterns, not DNS names: a wildcard can
never go into a certificate SAN or an nginx `server_name`, which is what the
`Wildcard` and `TLSNames` fields are for.

## Not everything is redirected

Two service values mean "do not send this to SwitchNet":

**`ServiceBlackhole`** — the telemetry hosts, null-routed to `0.0.0.0`. There is
nothing useful to do with a console's crash and play reports, and answering them
only fills the log.

**`ServicePassthrough`** — the `d4c` system-update hosts, which must keep
resolving to real Nintendo. **Do not null-route these.** The `nim` sysmodule
stores a persistent flag when the update check fails, and that flag survives
switching back to Nintendo's servers.

`hosts_test.go` asserts both, because getting the second one wrong is not
recoverable by changing the server.
