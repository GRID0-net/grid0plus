      Map and Salmon Run rotations

      Splatoon 2 does not ask its game server for rotations. It reads them from BCAT, the background delivery the console downloads on its own -- the game even has a debug scene for viewing the schedules BCAT delivered.

      GRID0+ answers every BCAT request with 304 Not Modified (internal/nintendo/hosts.go), so a console keeps whatever it last downloaded, and a console that never downloaded any has none. Serving Splatoon 2's BCAT is not done: it needs its data format and the console's verification of it worked out first, as Splatoon 3's does (TODO.md §2.4). Until then there is no rotation on this server to show or edit.

      Delivery cache

      Built by switchnetctl fest build -out and served to switch/bcat-installer from bcat.seed_dir. The id, resource and revision below are read from the summary.yml on disk — if they differ from the fest being announced, that difference is what produces BcatInvalid.

      Assets

      A pack is built from an assets directory, one subdirectory per pack. Files already in the game's formats — .bfres, .byaml, .sarc.zs — go in as they are.

      A source file is named for what it becomes, with the source extension appended: UI/Splashart.bfres.png becomes UI/Splashart.bfres, converted by whatever bcat.converter points at.

      GRID0+ does not convert textures itself, on purpose. A BFRES texture in the wrong compression or the wrong Tegra swizzle loads and renders as garbage — on the console, with nothing on the server to look at. Switch Toolbox and the BinaryTextureLibrary family already do it correctly. With no converter configured, a source file is a build error rather than a PNG packed into the archive.
