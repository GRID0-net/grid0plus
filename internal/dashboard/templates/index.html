    Delivery cache

    Built by switchnetctl fest build -out and served to switch/bcat-installer from bcat.seed_dir. The id, resource and revision below are read from the summary.yml on disk — if they differ from the fest being announced, that difference is what produces BcatInvalid.

    Assets

    A pack is built from an assets directory, one subdirectory per pack. Files already in the game's formats — .bfres, .byaml, .sarc.zs — go in as they are.

    A source file is named for what it becomes, with the source extension appended: UI/Splashart.bfres.png becomes UI/Splashart.bfres, converted by whatever bcat.converter points at.

    SwitchNet does not convert textures itself, on purpose. A BFRES texture in the wrong compression or the wrong Tegra swizzle loads and renders as garbage — on the console, with nothing on the server to look at. Switch Toolbox and the BinaryTextureLibrary family already do it correctly. With no converter configured, a source file is a build error rather than a PNG packed into the archive.

    Live tables

    Every row of the selected table, straight from the database. Read-only cells (keys, and anything another system depends on byte-for-byte) are dimmed; everything else is an Excel-style cell -- click in, edit, and it saves on blur or Enter. While "live" is on, the table re-polls every few seconds and any row a console or another tab changed flashes; a cell you are actively editing is never overwritten mid-edit.
